A milestone for SVLS LABS

Don't Ask AI for a Finished Song. Ask It for the Session.

CuTTI has reached an important development milestone. It is our production assistant for Logic Pro, built on the Model Context Protocol (MCP), and it now builds a working Logic Pro session from a written brief.

The idea is straightforward. Instead of asking AI to generate a finished song, ask it to help build the session you actually want to produce from.

Describe the musical direction. CuTTI interprets that intent and turns it into an editable Logic Pro workflow, with tracks, MIDI, song sections and arrangement structure that you keep shaping.

06

How it works

From Prompt to Project in Seven Stages.

CuTTI is an MCP server: it gives an AI assistant a defined set of Logic Pro tools and coordinates them as verified actions. MCP is the open standard for connecting AI assistants to tools.

  1. 01

    Producer Prompt

    You describe the song: genre, mood, tempo, instruments and structure, in plain words.

  2. 02

    Intent & Template Parser

    Understands the intent and extracts structure, genre, instruments and style.

  3. 03

    SongPlan & Arrangement Engine

    Creates a song structure with sections, a track plan and the musical decisions behind it.

  4. 04

    Genre & Instrument Knowledge Base

    Styles, instruments, idioms and arrangement patterns for rich, realistic results.

  5. 05

    MCP Orchestrator

    Coordinates tools, planning and execution, one verified action at a time.

  6. 06

    Logic Pro Automation Layer

    Turns the plan into a real Logic Pro project through Logic Pro's own actions.

  7. 07

    Editable Logic Pro Project

    A fully arranged project opened in Logic Pro. Tweak it, mix it and make it yours.

What the automation layer does

  • MIDI generation
  • Arrangement templates
  • Track creation
  • Section edits
  • Project save and bounce

10

Questions

Is CuTTI a music generator?

No. It does not hand you a finished track. It builds an editable Logic Pro session, with tracks, MIDI, song sections and arrangement structure, that you keep producing from.

Who makes the creative decisions?

You do. CuTTI proposes and builds; every track, region and note stays editable, and the mix, the sound and the final call stay with the producer.

Does it replace my MIDI packs and templates?

It does not have to. It creates a starting structure around your direction, and your own libraries, sounds and templates stay part of the workflow.

What is MCP?

The Model Context Protocol, an open standard that lets an AI assistant use tools. CuTTI is an MCP server: it gives the assistant a defined set of Logic Pro actions and coordinates them as verified steps.

Which DAW does it work with?

Logic Pro on macOS. Supported versions, system requirements and pricing are published at launch.

When can I use it?

CuTTI launches on 12 November 2026. Register for launch updates and we will write before launch, including early-access details.

Is the video the final product?

No. It is a development demo recorded on a development build. The launch build may look and behave differently.

Is CuTTI made by Apple?

No. CuTTI is an independent product by SVLS LABS LLP. Logic Pro is a trademark of Apple Inc., and CuTTI is not affiliated with, sponsored or endorsed by Apple.
